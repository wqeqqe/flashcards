如何讓它自動讀取？（任選一種）
方法 1：使用 Python（免安裝工具）
把 index.html 與你的 TestAdmit.xlsx 放在同一資料夾，在該資料夾打開終端機執行：
python -m http.server 8000
然後在瀏覽器打開 http://localhost:8000 即會自動讀取！
方法 2：VS Code 擴充套件
在 VS Code 安裝 Live Server，在 index.html 上按右鍵選擇 Open with Live Server。
